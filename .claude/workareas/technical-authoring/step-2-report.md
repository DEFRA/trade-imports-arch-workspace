1. Layout Rules in `plan-template.md` state a completeness rule for each form. A full plan needs every field, an item in every section and an answering section for every question. A short-artefact plan holds a `Purpose` and at least one point, no file check runs, and the skill asks the author for anything missing.

5. The line-editing pairs sit in one table with each passage in code font, which saves words and keeps the before text out of the prose gate. The list pair describes its after text instead of showing the bullets.
