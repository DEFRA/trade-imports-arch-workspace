# Language

A preface paragraph that the parser ignores.

## Banned Words and Phrases

Replace every use.

| Term | Repair |
| --- | --- |
| `frobnicate`, `frobnicates` | name the operation |
| `widget*` | name the component |
| `make use of`, `don't worry` | use, or state the risk |
| `you`, `your`, `yours` (documents for people only) | name the actor |
| `portal` in lower case as a generic noun | website or service |

## Words to Examine

Each of these has a literal sense that stays.

| Term | Repair |
| --- | --- |
| `simply` | delete the word |
| `gizmo`, `gizmos` as a verb | keep a literal use |

## Judgement Calls

These words have no row: gadget, contraption.

## Patterns

| Pattern | Repair |
| --- | --- |
| A heading that opens on what | name the topic |
| An em dash, a spaced en dash or a spaced hyphen used as a sentence break | a full stop, a comma or a colon |
| A curly quote | a straight quote |
| `N/A` in text or a table cell | state the fact |
| A sentence or line that ends on the pronoun `it` | name the noun |
